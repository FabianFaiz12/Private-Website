About me

Nama saya adalah Fabian Faiz, saya adalah seorang anak SMA dari SMA 74 Jakarta, tujuan saya membuat website ini adalah saya ingin menunjukan beberapa beberapa supercar yang saya temukan saat saya sedang melakukan spoting, lalu saya juga ingin memberikan informasi terhadap beberapa mobil yang saya tampilkan, informasinya berisi ialah seri supercar tersebut, sejarah, bahkan fakta unik supercar.

Hobi saya adalah bermain game dan membaca buku ataupun novel namun kadang saya juga suka mencari tahu hal baru entah itu tentang ilmu maupun hal lain yang menarik, di website ini saya hanya ingin menunjukan beberapa mobil telah saya temukan dan hobi maupun hal hal yang saya lakukan. Saya rasa cukup untuk pengenalan tentang saya maupun website saya, mohon maaf jika ada kesalahan di website ini, Terimakasih.
